# 雨落今天做了啥

今天凌晨被舍友的呼噜声吵的睡不好觉，虽然带着耳机，但是三更半夜的还有人开灯上厕所不关，给我照醒了。索性不睡了，开始研究博客。

<!--more-->

我对比了目前大部分流行的博客搭建工具，最后锁定在 Hexo 和 Hugo 之间。Hexo 我已经部署好了，大家都说它的主题功能多、质量高，我后面也尝试了 butterfly 这个主题——功能确实非常丰富，官方文档也讲得很详细。我其实挺喜欢这个主题的，感觉能一直用到毕业。但它太重了，虽然功能多，大部分我却用不上；而且那篇攻略真的长得可怕，我滑了好久才到底，更别说记住了。可能我更适合轻量化的博客吧，所以我最终选了 Hugo 作为框架、PaperMod 作为主题。

第一眼看到 PaperMod 的 demo 界面时，我的感受是：真简洁啊，简洁到有点简陋，什么功能也没有。这种感受在我把它部署起来之后更强烈了——虽然名字里带个“Mod”，可选功能却少得可怜。可能还是我不够了解它吧，后面得再翻翻 wiki。

第二是 Hugo 给我的惊喜：它的文档居然是可以实时同步的。我改动文件夹里的 md 文档，网站上的内容就跟着变，这和我之前用的 Hexo 完全不同。Hexo 每编辑一次文档都要重新构建一遍博客，等文章多起来之后，构建一次大概会很久——这也是我决定放弃 Hexo 的一个原因。

我原本以为 Hugo 的自动同步特性能在 GitHub 上也生效，然而我想多了。写好帖子之后依旧要重新构建一次博客，再加上 GitHub 的队列，时间就更长了。可能我发布好帖子之后，要过个两三分钟才能在网站上看到同步过来的文档，这和我之前用 Hexo 的五秒同步差得太多了。

除去博客，今天还是只上一节英语课。书也没带，就拿着个笔记本去第一排听课了，感觉也没听进什么。可能我还是更喜欢系统化的学习吧，这种零散拼凑的记忆实在记不住。

放学回家依旧被锁在门外了。和上次不同的是，这次我敲门时，能给我开门的都在睡觉。没招，还是去 linlee 喝奶茶吧。奶茶喝完，回家还是没人开门，时间已经过去了两个小时——醒着的装睡，睡着的醒不来。行吧，继续去 linlee 坐着。这回消息来了：醒了。那就回家吧。不过每次被这么搞一下确实会影响心情，但也就算了吧，不和小孩子计较。

不过这次老师给了我个惊喜：论文顺利通过，只有少数地方要改；获奖名单也通过了，这个好诶。本来以为没机会的，没想到因为我的分数还不错，我拿到了这张入场券。嗯嗯，加油吧。

这次光遇和 mc 还是玩得三心二意的，跑了七根蜡。计划做个刷石机，进度还是没什么进展。今天大概就这样吧，明天改论文、准备演讲稿。晚安。
